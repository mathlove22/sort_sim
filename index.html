알고리즘 비교

알고리즘 시간 복잡도 (최선) 시간 복잡도 (최악) 장점 단점
버블 정렬 O(n²) O(n²) 구현이 매우 간단하고 직관적임 데이터가 많을수록 속도가 매우 느림
선택 정렬 O(n²) O(n²) 구현이 간단하며, 값 교환(swap) 횟수가 적음 데이터가 많을수록 속도가 매우 느림
삽입 정렬 O(n) O(n²) 데이터가 이미 거의 정렬되어 있는 경우 매우 빠름 데이터가 많고 역순에 가까울수록 느림
병합 정렬 O(n log n) O(n log n) 어떤 데이터든 항상 일정한 빠른 속도를 보장함 다른 정렬에 비해 알고리즘 구조가 복잡함
퀵 정렬 O(n log n) O(n²) 일반적으로 가장 빠르고 효율적임 피벗 선택에 따라 최악의 경우 속도가 느려질 수 있음

* 시간 복잡도: 데이터의 개수(n)에 따라 알고리즘이 작업을 완료하는 데 걸리는 대략적인 시간(연산 횟수)을 나타냅니다.

Python 코드 예시

버블 정렬 (Bubble Sort)

data = [50, 23, 9, 18, 61, 32]
swap_count = 0
n = len(data)

for i in range(n - 1):
    for j in range(n - 1 - i):
        if data[j] > data[j + 1]:
            data[j], data[j + 1] = data[j + 1], data[j]
            swap_count += 1

print("정렬 결과:", data)
print("교환 횟수:", swap_count)

선택 정렬 (Selection Sort)

data = [50, 23, 9, 18, 61, 32]
swap_count = 0
n = len(data)

for i in range(n - 1):
    min_idx = i
    for j in range(i + 1, n):
        if data[j] < data[min_idx]:
            min_idx = j
    if min_idx != i:
        data[i], data[min_idx] = data[min_idx], data[i]
        swap_count += 1

print("정렬 결과:", data)
print("교환 횟수:", swap_count)

삽입 정렬 (Insertion Sort)

data = [50, 23, 9, 18, 61, 32]
shift_count = 0
n = len(data)

for i in range(1, n):
    key = data[i]
    j = i - 1
    while j >= 0 and data[j] > key:
        data[j + 1] = data[j]
        shift_count += 1
        j -= 1
    data[j + 1] = key

print("정렬 결과:", data)
print("이동 횟수:", shift_count)

병합 정렬 (Merge Sort)

data = [50, 23, 9, 18, 61, 32]

# 1. 각 숫자를 1개짜리 리스트로 분리
lists = [[x] for x in data]

# 2. 리스트가 1개로 합쳐질 때까지 2개씩 병합
while len(lists) > 1:
    left = lists.pop(0)
    right = lists.pop(0)
    merged = []

    # 두 리스트의 맨 앞 값을 비교하여 작은 순서대로 추가
    while left and right:
        if left[0] <= right[0]:
            merged.append(left.pop(0))
        else:
            merged.append(right.pop(0))

    # 남아있는 요소들 추가
    merged.extend(left + right)
    lists.append(merged)

data = lists[0]
print("정렬 결과:", data)

퀵 정렬 (Quick Sort)

data = [50, 23, 9, 18, 61, 32]

# 분할할 묶음들을 보관하는 목록
groups = [data]
result = []

while groups:
    current = groups.pop()

    # 원소가 1개 이하면 이미 정렬된 상태
    if len(current) <= 1:
        result.extend(current)
        continue

    pivot = current[0]
    left = []
    right = []

    # 피벗을 기준으로 작은 값은 left, 큰 값은 right로 분리
    for x in current[1:]:
        if x <= pivot:
            left.append(x)
        else:
            right.append(x)

    # 오른쪽 그룹, 피벗, 왼쪽 그룹 순서로 담기
    groups.append(right)
    groups.append([pivot])
    groups.append(left)

data = result
print("정렬 결과:", data)

활용 사례

  • 버블 정렬 (Bubble Sort):
    • - 교육적인 목적으로 알고리즘의 기본 원리를 설명할 때 주로 사용됩니다.
    • - 데이터 크기가 매우 작거나 코드를 단순하게 유지해야 할 때 사용됩니다.
  • 선택 정렬 (Selection Sort):
    • - 버블 정렬과 마찬가지로 알고리즘 개념 학습용으로 많이 쓰입니다.
    • - 데이터의 교환 횟수를 최소화해야 하는 상황에서 유용합니다.
  • 삽입 정렬 (Insertion Sort):
    • - 데이터 크기가 작거나, 데이터가 이미 거의 정렬되어 있는 경우 매우 빠릅니다.
    • - 새로운 데이터가 하나씩 계속 추가되는 상황에서 정렬을 유지할 때 유용합니다.
  • 병합 정렬 (Merge Sort):
    • - 데이터 양이 많더라도 항상 일정한 빠른 속도(O(n log n))를 보장해야 할 때 사용됩니다.
    • - 분할 정복(Divide and Conquer) 개념을 학습할 때 대표적인 예시로 활용됩니다.
  • 퀵 정렬 (Quick Sort):
    • - 평균적으로 속도가 매우 빨라 실제 다양한 프로그래밍 언어와 시스템에서 널리 활용됩니다.
    • - 기준값(피벗)을 정하고 둘로 나누는 직관적인 원리로 동작합니다.
