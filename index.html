* **시간 복잡도**: 알고리즘이 입력 크기(n)에 따라 실행되는 데 걸리는 시간을 나타냅니다. 숫자가 작을수록 효율적입니다.
* **공간 복잡도**: 알고리즘이 실행되는 동안 사용하는 추가적인 메모리 공간의 양을 나타냅니다.
* **안정성 (Stable)**: 정렬 후에도 값이 같은 요소들의 상대적인 순서가 유지되는지 여부를 나타냅니다.

Python 코드 예시

버블 정렬 (Bubble Sort)


def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        swapped = False
        # 마지막 i개 요소는 이미 정렬됨
        for j in range(0, n - i - 1):
            # 인접한 두 요소를 비교하여 필요시 교환
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        # 이번 패스에서 교환이 없었다면 이미 정렬된 상태
        if not swapped:
            break
    return arr

선택 정렬 (Selection Sort)


def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        # 현재 인덱스를 최소값의 인덱스로 가정
        min_idx = i
        # i+1부터 끝까지 탐색하며 최소값 인덱스 찾기
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j
        # 찾은 최소값과 현재 위치(i)의 값을 교환
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

삽입 정렬 (Insertion Sort)


def insertion_sort(arr):
    n = len(arr)
    # 첫 번째 요소는 이미 정렬된 것으로 간주 (i=1부터 시작)
    for i in range(1, n):
        key = arr[i] # 현재 삽입할 요소
        j = i - 1
        # key보다 큰 요소들을 오른쪽으로 한 칸씩 이동
        while j >= 0 and key < arr[j]:
            arr[j + 1] = arr[j]
            j -= 1
        # 적절한 위치에 key 삽입
        arr[j + 1] = key
    return arr

병합 정렬 (Merge Sort)


def merge_sort(arr):
    if len(arr) > 1:
        mid = len(arr) // 2 # 중간점 찾기
        left_half = arr[:mid] # 왼쪽 부분 배열
        right_half = arr[mid:] # 오른쪽 부분 배열

        # 재귀적으로 각 부분을 정렬
        merge_sort(left_half)
        merge_sort(right_half)

        # 정렬된 두 부분을 병합
        i = j = k = 0 # i: left_half 인덱스, j: right_half 인덱스, k: arr 인덱스
        while i < len(left_half) and j < len(right_half):
            if left_half[i] < right_half[j]:
                arr[k] = left_half[i]
                i += 1
            else:
                arr[k] = right_half[j]
                j += 1
            k += 1

        # 남은 요소들 처리
        while i < len(left_half):
            arr[k] = left_half[i]
            i += 1
            k += 1
        while j < len(right_half):
            arr[k] = right_half[j]
            j += 1
            k += 1
    return arr

퀵 정렬 (Quick Sort)


def quick_sort(arr):
    # 내부 함수로 재귀 구현 (시작, 끝 인덱스 사용)
    def _quick_sort_recursive(items, low, high):
        if low < high:
            # 분할 (Partition) 후 피벗 위치 반환
            pivot_index = _partition(items, low, high)
            # 피벗 기준 왼쪽 부분 배열 정렬
            _quick_sort_recursive(items, low, pivot_index - 1)
            # 피벗 기준 오른쪽 부분 배열 정렬
            _quick_sort_recursive(items, pivot_index + 1, high)

    # 분할 함수 (Hoare partition scheme 사용 예시)
    def _partition(items, low, high):
        pivot = items[low] # 첫 번째 요소를 피벗으로 선택 (다양한 전략 가능)
        left = low + 1
        right = high

        done = False
        while not done:
            # 왼쪽에서 피벗보다 큰 값 찾기
            while left <= right and items[left] <= pivot:
                left += 1
            # 오른쪽에서 피벗보다 작은 값 찾기
            while right >= left and items[right] >= pivot:
                right -= 1

            if right < left: # 인덱스가 엇갈리면 분할 완료
                done = True
            else: # 찾은 두 값을 교환
                items[left], items[right] = items[right], items[left]

        # 피벗과 오른쪽 포인터 위치의 값을 교환하여 피벗 위치 확정
        items[low], items[right] = items[right], items[low]
        return right # 피벗의 최종 위치 반환

    # 실제 정렬 시작
    _quick_sort_recursive(arr, 0, len(arr) - 1)
    return arr

활용 사례

  • 버블 정렬 (Bubble Sort):
    • - 교육적인 목적으로 알고리즘의 기본 원리를 설명할 때 주로 사용됩니다.
    • - 데이터 크기가 매우 작거나, 코드를 극도로 단순하게 유지해야 할 때 제한적으로 사용될 수 있습니다.
  • 선택 정렬 (Selection Sort):
    • - 버블 정렬과 마찬가지로 교육용으로 많이 쓰입니다.
    • - 쓰기(swap) 연산이 비용이 많이 드는 경우 (예: 플래시 메모리)에 고려될 수 있습니다 (이론적으로).
  • 삽입 정렬 (Insertion Sort):
    • - 데이터 크기가 작을 때 효율적입니다. (다른 복잡한 정렬 알고리즘의 기본 케이스로 사용되기도 함)
    • - 데이터가 이미 거의 정렬되어 있는 경우 매우 빠르게 동작합니다.
    • - 실시간으로 데이터가 계속 들어오는 '온라인' 상황에서 유용할 수 있습니다.
  • 병합 정렬 (Merge Sort):
    • - 데이터 크기가 큰 경우에도 안정적인 성능(O(n log n))을 보장해야 할 때 사용됩니다.
    • - 외부 정렬(메모리에 모든 데이터를 올릴 수 없을 때)에 유용합니다.
    • - 안정 정렬이 필요한 경우 (예: 여러 기준으로 정렬할 때) 사용됩니다.
  • 퀵 정렬 (Quick Sort):
    • - 평균적으로 가장 빠른 정렬 알고리즘 중 하나로 알려져 있어, 많은 프로그래밍 언어의 표준 라이브러리 정렬 함수 구현에 사용됩니다.
    • - 추가 메모리 사용량이 비교적 적습니다 (평균 O(log n)).
    • - 캐시 효율성이 좋은 편입니다.
